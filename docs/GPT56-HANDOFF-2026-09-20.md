## Points à préserver

- Panic LOCAL préserve le kit externe ; DISTANT exige une option explicite et ne garantit pas les copies d'un serveur hostile.
- Pas d'accès aux bases privées des apps Signal/Telegram officielles ; pas d'effacement automatique de leurs données.
- Pas de révocation serveur Telegram garantie hors ligne ; ne pas conserver une session de lecture pour la retenter.
- Pas d'auto-désinstallation ni désactivation du lanceur : conserver une reprise accessible tant qu'une action est incomplète.
- Ni clé de récupération ni token de lecture dans une capsule de retry ; aucune donnée sensible dans logs/data classes.
- Pas de fraîcheur prouvable sur un nouvel appareil sans checkpoint externe ; afficher cette limite.
- Un seul commit cohérent par lot, lire repo-factory avant Git, valider le SHA final. Pas d'APK sans demande.
